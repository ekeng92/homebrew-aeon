# Homebrew AEON

Public Homebrew tap for approved, compiled AEON application releases. Application source remains in private repositories.

Pilot Controls will be listed here after a signed and notarized release ZIP is available. No Casks are published yet.

The planned install command is:

```sh
brew tap ekeng92/aeon
brew install --cask pilot-controls
```

Do not use the command until `Casks/pilot-controls.rb` is published for an approved release.
